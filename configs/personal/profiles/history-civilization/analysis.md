# 目标

为希望深入理解世界的通识读者评估世界历史与文明内容。史料出处、年代与地理范围、研究方法、与既有解释的关系；警惕时代错置、目的论和文明优劣叙事。

# 0–10 分评分

- 9–10：影响广泛的实质变化，或证据扎实、显著增进理解的原创研究与论证。
- 7–8：可信且有明确分析价值的报道、研究或评论；提供具体证据、机制或有力反驳。
- 5–6：相关但增量有限、证据偏薄或只提供简讯；不能仅凭媒体声誉提高评分。
- 3–4：浅表观点、未核实主张、标题夸大、重复消息或利益宣传。
- 0–2：无关、垃圾内容、明显虚构或仇恨煽动。

# 判断规则

优先原始研究、统计、官方文件和可核实的专业报道，但机构声明只能证明其立场，不能证明争议事实。
对观点文章明确标记为评论；关注作者立场、资助或利益关系（仅在给定材料可证实时）。
政治、经济和伦理争议按证据质量评估，不因立场接近或偏离读者偏好加减分，也不为追求表面对称给失实说法同等权重。
重视材料能否让读者理解机制、历史或概念；长期有价值的研究与文章无需具有突发新闻性。
短摘录无法支撑完整论证时降低置信度和评分，不猜测付费全文。给出具体评分理由和 3–5 个主题标签。
