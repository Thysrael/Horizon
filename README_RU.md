# InfoService — руководство оператора и пользователя

InfoService — самостоятельный Telegram-бот для персональных информационных отчётов. Он использует Horizon как движок сбора и обработки, а DeepSeek подключается по модели BYOK: каждый пользователь вводит свой ключ.

## Быстрый запуск

1. В [@BotFather](https://t.me/BotFather) создайте бота и сохраните токен.
2. Скопируйте `.env.example` в `.env`. Укажите токен, пароль PostgreSQL и новый Fernet-ключ `APP_ENCRYPTION_KEY`.
3. Выполните `docker compose up -d --build`.
4. Откройте бота в личном чате, выберите часовой пояс и добавьте ключ DeepSeek.

После миграции запускаются три процесса: `bot` принимает команды, `scheduler` ставит отчёты в очередь, `worker` собирает источники и отправляет результат. В группах бот направляет пользователя в личный чат.

## Возможности и ограничения

- Не более 5 отчётов и 30 источников в одном отчёте.
- RSS, публичные Telegram-каналы, Hacker News и GitHub — стабильные источники.
- Reddit, Google News, GDELT и OSS Insight — beta.
- Twitter/X и OpenBB включаются оператором: `APP_IMAGE_TARGET=runtime-full` плюс соответствующий `ENABLE_*` флаг.
- Расписания: ежедневно, будни, еженедельно или cron с минимумом один час; история хранится 30 дней.
- Пользователь задаёт порог, категории, исключения, глубину поиска, язык и дополнительную инструкцию до 2000 символов.

## Безопасность ключей

Ключ DeepSeek удаляется из входящего сообщения Telegram, проверяется и хранится только в зашифрованном виде в PostgreSQL. Он не записывается в `.env`, логи, отчёты или сообщения об ошибках. Удаление ключа в меню LLM отключает отчёты пользователя. Не публикуйте `.env`, резервные копии БД или `APP_ENCRYPTION_KEY`.

## Эксплуатация

Проверьте состояние: `docker compose ps` и `docker compose logs -f worker`. Резервная копия БД:

```bash
docker compose exec -T postgres pg_dump -U infoservice infoservice > backup.sql
```

Для восстановления создайте чистую БД и импортируйте файл через `psql`. Обновление кода: получите новую версию, проверьте `.env`, затем выполните `docker compose up -d --build`; миграции применятся до запуска процессов. Не меняйте Fernet-ключ без процедуры пере-шифрования существующих credentials.
