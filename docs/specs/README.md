# Specifications

This directory contains stable product and architecture specifications for planned Horizon capabilities.

Specifications use **MUST**, **SHOULD**, and **MAY** in the same way as RFC 2119. “MUST” requirements are mandatory; “SHOULD” requirements express a strong preference that may be waived with documented rationale; “MAY” requirements describe permitted behavior.

## Index

- [Daily Intelligence Brief Vision Specification](daily-intelligence-brief-vision.md) - Constitutional direction for the future personalized intelligence platform.
- [Feedback Learning Specification](feedback-learning.md) - Rules for feedback signals, preference learning, recommendation outcomes, and anti-echo-chamber safeguards.
- [Editorial Steering Specification](editorial-steering.md) - Rules for relevance, project awareness, recency, exploration, modes, and auditable editorial influence.
- [Recommendation Engine Specification](recommendation-engine.md) - Rules for recommendation artifacts, provenance, lifecycle, lineage, outcomes, fatigue, and agent accountability.
- [Context Collection Specification](context-collection.md) - Rules for source adapters, normalized activity records, project inference, redaction, freshness, and collection degradation.
- [Work Context Brief Specification](work-context-brief.md) - Rules for the compact, versioned operational snapshot handed between collection and downstream intelligence.
- [Daily Intelligence Delivery Platform Specification](daily-intelligence-delivery-platform.md) - Rules for editions, channels, archives, feedback, privacy, accessibility, and the reading experience.
- [Agent Accountability Specification](agent-accountability.md) - Rules for agent identity, provenance, outcome metrics, calibration, attribution, influence, and retirement.
- [Archive and Longitudinal Intelligence Specification](archive-longitudinal-intelligence.md) - Rules for editions and durable records, review horizons, pattern detection, drift, lineage, retention, and deletion.
- [Memory Architecture Specification](memory-architecture.md) - Rules for working, episodic, semantic, strategic, and archived memory, retrieval, decay, consolidation, contradiction, and governance.
- [Knowledge Layer Specification](knowledge-layer.md) - Rules for concepts, themes, patterns, principles, ontology, relationships, contradiction, and knowledge evolution.
- [Reasoning Layer Specification](reasoning-layer.md) - Rules for evidence-backed judgment, critique, risk and opportunity detection, assumptions, contradiction, confidence, and traceability.
- [Chief of Staff Orchestration Specification](chief-of-staff-orchestration.md) - Rules for workflows, triggers, agent coordination, quality gates, retries, delivery, learning, and human authority.
- [Specification Stewardship Triage](stewardship-triage.md) - Cross-spec review, priority findings, contradictions, missing specifications, and recommended implementation order.
